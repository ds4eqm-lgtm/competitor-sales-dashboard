자재별 추정 현황

재고 감소에는 주문 외 재고 조정·출고·타 채널 판매가 포함될 수 있습니다. 미관측·장기 공백·이상 변동은 일반 추정과 구분합니다.

경쟁사별 조회

경쟁사명을 선택하면 해당 업체의 상품·재고·주간/야간 감소 추정을 조회합니다.

자재별 조회

상품별 재고 현황

옵션별 관측 재고와 마지막 수집 시각, 주간·야간 감소를 표시합니다. 수집 기록이 없으면 '수집 대기'입니다.

날짜별 판매 추정

날짜를 누르면 그날 07:00~다음 날 07:00 기록을 표시합니다. 파란 테두리는 관측 기록이 있는 날입니다.

선택일 관측 구간

평수별 대량 감소 검색

이상 변동 분석

급격한 재고 변화, 증가, 장기 관측 공백을 검토 대상으로 분리합니다. 이상 변동만으로 재고 조작·가매출을 판단할 수 없습니다.

수집 대상 URL 등록 · 수정 · 중지 · 삭제

상품 URL을 추가하면 GitHub config/products.json에 저장합니다. 저장은 GitHub Pages에 배포한 화면에서만 가능합니다. 이 PC에서 파일을 직접 연 미리보기에서는 등록을 시도하지 않습니다.

GitHub 저장 준비 중

중지한 상품은 목록에 남기되 수집 대상에서 제외합니다. 삭제는 수집 목록에서만 제거하며 과거 재고 기록은 삭제하지 않습니다.

상품·옵션별 면적 및 자재 분류

기본 환산: 600각 9장, 450·457각 16장, 300각 36장 = 1평. 상품·옵션별로 박스/낱장/반평을 따로 지정합니다. 설정은 현재 브라우저에 저장되므로 백업을 권장합니다. 미설정 옵션의 평수는 임의로 계산하지 않습니다.

자동 방문·재고 수집

시작하면 별도 작업 창에서 순회합니다. 이 대시보드와 작업 창을 켜두세요. 기존 BAT 자동 순회는 중복 실행하지 마세요.

Tampermonkey 연결 확인 중

최소 대기 이후 수집 완료 시 다음 상품으로 이동합니다. 시간 초과는 실패로 기록합니다. 이전 회차가 길어지면 중복 회차를 실행하지 않습니다.

GitHub 데이터 연결

기존 상품목록(config/products.json)과 새 수집기 기록(data/history.json, data/latest.json)을 함께 읽습니다. 파일이 아직 없는 경우에는 해당 항목을 수집 대기로 표시합니다. 기존 v2 데이터(records.json)도 보조로 읽습니다.

연결 파일 상태

아직 확인하지 않았습니다.

오프라인 데이터 가져오기

GitHub 접속에 문제가 있을 때 데이터를 임시로 열람할 수 있습니다. GitHub 업로드 기능은 포함하지 않습니다.
